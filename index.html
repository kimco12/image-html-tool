이미지 → HTML 변환기

이미지를 업로드한 순서대로(또는 드래그로 재정렬해서) 이어붙여, 상세페이지용 HTML 코드를 만듭니다. 모든 처리는 브라우저 안에서만 이루어지며 서버로 전송되지 않습니다.

필름스트립

    이미지 압축

    여기서 용량을 줄이면 2단계 HTML 변환의 "내장(base64)" 코드 용량도 함께 줄어듭니다. 쇼핑몰에 등록할 때 413(용량 초과) 오류가 나면 먼저 이 단계를 적용해보세요.

      변환 설정

      0장
      내장 방식: 이미지 데이터가 HTML 파일 안에 그대로 포함되어 이 파일 하나만으로 어디서든 열립니다. 파일이 많거나 크면 결과 용량이 커질 수 있습니다.
      왼쪽에 이미지를 추가하고 "HTML 생성"을 누르면 여기에 코드가 나타납니다.

      무신사용 URL 매칭

      0장
      무신사 상품등록 에디터의 이미지 업로드 기능으로 이미지를 먼저 올린 뒤, 거기서 받은 실제 URL을 순서에 맞게 아래에 붙여넣으세요. base64 없이 URL만 들어간 가벼운 코드라 저장 시 중간에 잘리지 않습니다.
        URL을 모두 입력하고 "HTML 생성"을 누르면 여기에 코드가 나타납니다.
