# 이미지 → HTML 변환기 (v3)

브라우저 안에서만 동작하는 이미지 → 상세페이지 HTML 변환 도구입니다. **이미지가 서버로 전송되지 않고**, 모든 압축·변환·미리보기가 내 컴퓨터(브라우저) 안에서만 처리됩니다.

- 온라인 사용: https://kimco12.github.io/image-html-tool/
- 로컬 파일: `이미지 HTML 변경 툴 v3.html` (더블클릭하면 브라우저에서 바로 열림)

---

## 사용 순서 (기본 흐름)

1. **파일 받기** — (구글 드라이브에서) 오른쪽 상단 **⋮** 클릭 → **파일 옵션** → **다운로드**
   (또는 위 GitHub Pages 링크로 바로 접속해도 동일하게 사용 가능 — 이 경우 다운로드 단계는 생략)
2. **이미지 업로드** — 왼쪽 "필름스트립" 영역에 이미지를 드래그하거나 클릭해서 선택
3. **압축** — 필요 시 1단계 "이미지 압축" 탭에서 용량 줄이기
4. **HTML 변환 탭** — 2단계 탭으로 이동해 출력 옵션 설정
5. **변환** — "HTML 생성" 버튼 클릭
6. **코드 복사** — "코드 복사" 버튼으로 클립보드에 복사
7. **상품등록 사이트로 이동**
8. **상세페이지 코드 등록** — 상품등록 사이트의 HTML 편집 영역에 붙여넣기(Ctrl+V)
9. **등록**
10. **저장**

## 화면 구성 & 기능 설명

### 공통 — 필름스트립 (왼쪽 패널)
- **이미지 추가**: 드롭존을 클릭하거나 이미지 파일을 드래그 앤 드롭. 여러 장을 한 번에 선택 가능.
- **순서**: 추가한 순서대로 번호가 매겨지며, 이 번호 순서 그대로 HTML의 `<img>` 태그 순서가 됩니다.
- **순서 변경**: 각 이미지를 마우스로 드래그해서 위/아래로 재정렬 가능.
- **삭제**: 이미지 오른쪽 ✕ 버튼으로 개별 삭제, 상단 "전체 지우기"로 전부 삭제.
- 이미지 옆에 파일 크기가 표시되며, 압축을 적용하면 "원본 크기 → 압축 후 크기 (-N%)" 형태로 절감률까지 함께 표시됩니다.

### 1단계 — 이미지 압축 (선택 사항)
용량이 큰 이미지를 그대로 HTML에 넣으면(특히 "내장" 방식) 결과 파일이 너무 커져서 쇼핑몰 등록 시 **413(용량 초과) 오류**가 날 수 있습니다. 이를 막기 위한 사전 압축 단계입니다.

- **최대 가로 너비(px)**: 이보다 큰 이미지는 이 너비로 축소(기본 1200px). 세로는 비율 유지.
- **압축 품질(%)**: JPEG 압축 품질(기본 80%). 낮을수록 용량은 작아지지만 화질도 떨어짐.
- **출력 형식**:
  - `JPEG로 압축 (권장)` — 대부분의 상세페이지 이미지에 적합, 용량 절감 효과 큼.
  - `원본 형식 유지 (투명배경 필요시)` — PNG 투명배경을 유지해야 하는 경우 선택.
- **압축 적용**: 위 설정대로 전체 이미지를 한 번에 압축 처리.
- **전체 원본으로 되돌리기**: 압축 이전 원본 상태로 복원.
- **전체 다운로드**: 압축된 이미지 파일들을 개별적으로 다운로드(파일명 참조 방식 사용 시 필요).
- 상단에 "총 OOMB → OOMB (-N%)" 형태로 전체 절감률이 요약 표시됩니다.

> 압축은 선택 사항입니다. 이미지 용량이 크지 않다면 건너뛰고 바로 2단계로 이동해도 됩니다.

### 2단계 — HTML 변환
실제로 상세페이지에 등록할 HTML 코드를 만드는 단계입니다.

- **이미지 소스 방식**
  - **내장 (base64)**: 이미지 데이터를 코드 안에 통째로 넣는 방식. 파일 하나(코드 한 덩어리)만 붙여넣으면 어디서든 그대로 보입니다. 이미지가 많거나 크면 코드 용량이 커짐 → 용량 초과 오류가 나면 1단계 압축을 먼저 적용.
  - **파일명 참조**: 코드에는 파일명만 들어가는 가벼운 방식. 이 경우 이미지 파일도 별도로 함께 업로드해야 정상적으로 보임(쇼핑몰 에디터가 파일명 참조를 지원하는 경우에만 사용).
- **이미지 너비**: `<img>` 태그의 width 값 (기본 `100%`, 컨테이너에 꽉 차게 표시).
- **컨테이너 최대 너비(px)**: 이미지들을 감싸는 영역의 최대 너비(기본 860px).
- **이미지 간격(px)**: 이미지 사이 여백(기본 0, 이미지끼리 딱 붙게).
- **완전한 HTML 문서로 감싸기**: 체크하면 `<!doctype html>`부터 시작하는 완전한 문서로 출력, 해제하면 상세페이지 에디터에 바로 붙여넣을 수 있는 코드 조각만 출력(대부분의 쇼핑몰 에디터는 이 체크를 **해제**하고 조각만 붙여넣는 것을 권장).
- **HTML 생성**: 위 설정대로 코드를 만듦.
- **코드 복사**: 생성된 코드를 클립보드로 복사.
- **.html 다운로드**: 생성된 코드를 파일로 저장.
- **코드 / 미리보기 탭**: "코드" 탭은 실제 텍스트, "미리보기" 탭은 만들어진 페이지가 실제로 어떻게 보이는지 즉시 확인 가능.
- 내장 방식 사용 시 전체 용량이 5MB를 넘으면 "결과 파일이 큽니다 · 압축을 적용해보세요" 경고가 표시됩니다.

### 3단계 — 무신사용 (무신사 상품등록 전용)
무신사는 상세페이지 코드에 이미지를 base64로 통째로 넣으면 저장 중간에 코드가 잘리는 경우가 있어, **실제 이미지 URL을 코드에 넣는 방식**을 따로 제공합니다.

- 사용 순서: 무신사 상품등록 에디터의 이미지 업로드 기능으로 이미지를 먼저 올린 뒤, 거기서 발급된 실제 이미지 URL(`https://image.msscdn.net/...`)을 이미지 순서에 맞게 하나씩 입력.
- URL을 비워둔 채 "HTML 생성"을 누르면 어떤 번호의 URL이 비어있는지 빨간 테두리 + 안내 메시지로 표시됩니다.
- 나머지(너비/컨테이너 너비/간격/완전한 문서로 감싸기, 코드 복사/다운로드/미리보기)는 2단계와 동일하게 동작합니다.
- base64가 없는 가벼운 코드이므로 저장 시 중간에 잘리지 않는 것이 장점입니다.

## 자주 겪는 문제

- **등록 시 413 / 용량 초과 오류** → 1단계에서 이미지 압축 먼저 적용 후 다시 변환.
- **무신사에서 상세페이지 저장이 중간에 끊김** → 2단계(내장 방식) 대신 3단계 "무신사용" 탭 사용.
- **파일명 참조 방식인데 이미지가 안 보임** → HTML 파일과 이미지 파일들을 같은 폴더(또는 같은 파일명으로 서버)에 함께 올렸는지 확인.
